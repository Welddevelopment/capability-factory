# Fresh-start onboarding teardown fixture

This is a fictional, local, deterministic input package for testing the
Capability Factory onboarding packaging path. It is deliberately unrelated to
the existing ERPNext, Gitea, Solstice, dispatch, procurement, browser, file,
inbox, and document helper worlds.

The package supplies the same categories a platform engineer would have to
bring to a real onboarding:

- one bounded workflow in ordinary business language;
- approved local OpenAPI material;
- credential aliases, never values;
- explicit authority and retry decisions;
- an independently observable definition of completion;
- reviewed action/observer binding declarations; and
- a disposable ten-case fixture contract.

The acceptance fixture is not a customer runtime and is not evidence that the
generated adapter works against a real system. Its purpose is to expose the
commands, confirmations, durable restart behavior, generated artifacts, and
remaining customer-specific implementation work in one clean rehearsal.

# Known issues at freeze

- Supported product mode is constrained documented HTTP APIs inside a predefined trusted scope.
- A platform engineer must still confirm consequential facts and implement any unsupported observer/runtime primitive.
- This kit has not been run by a fresh engineer.
- The kit does not test arbitrary APIs, undocumented systems, browser workflows, production credentials, regulated data, or customer deployment.
- Exact setup time and remaining bespoke work are unknown until the independent run.
- The adapter/observer factories are deterministic in this zero-spend version; model-assisted proposals are outside this protocol.
- The participant environment still assumes a local Node/pnpm toolchain and the repository’s current installation shape.

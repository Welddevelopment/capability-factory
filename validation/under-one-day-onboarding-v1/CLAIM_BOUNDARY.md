# Claim boundary

- Kit preparation is not a human result.
- The deterministic Solstice development run is not a fresh-engineer result.
- Generated adapter, authority, observer, or acceptance scaffolds are not passing evidence.
- Declared tests are not executed tests.
- Self-timing by the author is not independent onboarding evidence.
- One independent run is not repeatability or generality.
- A Capability Factory versus manual comparison is valid only when both arms implement equivalent authority, independent observation, lost-response reconciliation, and the same ten safety cases.
- No action response may serve as independent proof of the external business outcome.
- A participant request for author/domain hints must be logged. Unscripted author help invalidates the no-help result.
- Any surviving incorrect external side effect aborts the run.

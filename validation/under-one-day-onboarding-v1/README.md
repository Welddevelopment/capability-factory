# Under-One-Day Capability Factory Onboarding Validation Kit v1

Status: **prepared, frozen after deterministic tooling QA, not independently executed**.

This kit tests one claim: can a fresh product/platform engineer connect Capability Factory to one supported, documented HTTP system in less than one working day, without manually implementing each missing integration, while preserving authority, independent outcome verification, reconciliation, and all ten mandatory acceptance cases?

The kit does not establish that claim. The Solstice joined run used to test the tooling was performed by the product-authoring task and is development evidence only. A valid result requires a fresh engineer, no author help, frozen inputs, a customer-like clarification protocol, preserved artifacts, and a separate evaluator.

## Reading order

1. `CLAIM_BOUNDARY.md`
2. `PROTOCOL.md`
3. `participant/START_HERE.md` (participant only)
4. `evaluator/SCORING_RUBRIC.json` and `evaluator/SEALED_ORACLE.json` (evaluator only)
5. `FROZEN_MANIFEST.json`

The participant must not receive `evaluator/` before submitting. Copy only `participant/` plus the product checkout identified in `FROZEN_MANIFEST.json`.

## Valid evidence

A single clean run under eight hours supports only: “one independent developmental onboarding run completed within one working day.” It does not prove repeatability, production readiness, customer validation, or comparative time savings. A comparative speed claim needs a fair manual arm with the same safety requirements.

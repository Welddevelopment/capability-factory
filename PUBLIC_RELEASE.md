# Public source release

This repository publishes the current Capability Factory product source,
experimental capability routes, tests, console, demo launchers, and technical
documentation. The first public snapshot was prepared on 25 September 2026.

The earlier development repository is preserved privately. Its unrelated founder
profiles, applications, referrals, outreach research and coordination records are
not part of this source release. Historical technical reports are retained with
their original dates and evidence boundaries; their referenced private runtime
artifacts are not automatically distributed.

New clones can run the source and generate fresh local evidence. They should not
assume that a historical artifact path exists or that a saved result is a new run.
No API key is required for explicitly deterministic routes. Model-backed routes
require a separately configured key and explicit run confirmation.

Repository visibility does not grant a new software licence. No MIT, Apache or
other open-source licence has been selected by this publication.
